# code-style
Source: d:\ism\.agents\skills\code-style\SKILL.md

Code style rules:
- Keep functions small. Split when a function has multiple jobs.
- Keep files under 300 lines when practical.
- Prefer object-oriented code over scattered functions.
- Higher-order/public functions near the top; utilities at the bottom.
- Terse, simple English comments explaining why, not what.
- Minimal change principle.
